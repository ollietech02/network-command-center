Restart controls every button asks first

DashboardRestarts the Network Command Center only. Nobody's internet is affected.
Pi-holeRestarts Pi-hole's DNS + DHCP. About a 5-second pause in lookups for the whole house.
This laptopFull reboot. Pi-hole is down for about 1-2 minutes, so the house can't load new sites until it's back.
House Wi-Fi (router)Not automated: the dashboard never signs in to your router. Do it by hand. Wi-Fi and internet go down for everyone for about 3-5 minutes:
  • Your router's app (most internet providers have one) → your router → Restart
  • Router settings page: open the router's address in a browser (often http://192.168.1.1 or http://192.168.0.1; it's printed on the router) → look for Restart or Reboot
  • Or unplug the router's power for 10 seconds and plug it back in

"No ping reply" is common for phones, TVs, and IoT devices and does not mean the device is offline or a threat. Device types are guesses from names/vendors only. Names you give devices are stored only in this dashboard; nothing is changed on the gateway or the device.

Private addresses: phones, tablets and watches usually join Wi-Fi with a made-up ("private") MAC address. On an iPhone set to Fixed, it stays the same for your network, so a name you give it sticks. Set to Rotating, it changes about every two weeks and the device reappears here as a new entry. When an unnamed private address has the same hostname as a device you named that's offline, the table asks whether it's the same device.

Allow & block lists

readyType a domain, then Block or Allow it, or Check what Pi-hole does with it now.
DomainListCoversNoteAdded

Changes apply to every device that uses this Pi-hole for DNS, and an allowed domain wins over the blocklists. Pi-hole applies a change within a second. The dashboard then does a test lookup and, if Pi-hole is still giving the old answer, restarts Pi-hole's DNS automatically. Phones and browsers keep their own DNS cache for a minute or two, so a change can take that long to show on a device.
